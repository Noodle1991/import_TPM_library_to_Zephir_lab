## КАВО

Это проект для запуска программ под **Zephyr 3.7.0** на модели чипа **OpenTitan EarlGrey** через **Docker** и **Verilator**.
Через **OpenOCD** и **GDB** можно подключаться к виртуальному **JTAG**, читать регистры процессора **Ibex** и отлаживать программу

Содержимое архива:

- Dockerfile и Dockerfile.cached-gdb — сборка Docker-окружения с Zephyr, OpenTitan, Verilator, OpenOCD
- и GDB. При наличии подходящего старого образа можно использовать его как основу
- scripts/ — команды для установки, сборки приложений, запуска симулятора и подключения отладчика
- container/scripts/ — внутренние скрипты запуска Verilator, OpenOCD и проверки GDB; здесь же находятся
- исправления JTAG/DMI и проверка Bazel
- myapp/ — пример приложения на C (myapp/src/main.c). Его можно изменять и собирать заново
- build/ — результаты предыдущей локальной сборки; на другом компьютере создаются заново
- logs/ — сохранённые логи запусков и проверок
- QUICKSTART-GDB.md, README-MAC.md — дополнительные инструкции
